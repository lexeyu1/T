Инструкция по использованию кода для генерации приватных ключей
Этот код предоставляет множество методов для генерации приватных ключей на основе координат эллиптической кривой (x и y) с использованием различных криптографических техник.

Установка необходимых зависимостей
Перед использованием убедитесь, что у вас установлены необходимые библиотеки:

pip install pycryptodome
Как использовать программу
Запуск программы:

Запустите скрипт командой python script_name.py

Ввод данных:

При запуске программа запросит координаты x и y эллиптической кривой.

Введите их в шестнадцатеричном формате (без префикса 0x).

Выбор метода генерации:

После ввода координат появится меню с 31 вариантом генерации приватных ключей.

Выберите нужный метод, введя соответствующую цифру.

Основные методы генерации:

Арифметические операции (сложение, умножение, XOR)

Комбинации с базовой точкой кривой

Использование параметров λ и β кривой secp256k1

Различные виды хеширования (SHA256, CRC32)

Криптографические операции (AES, PBKDF2)

Перестановки и битовые операции

Генерация псевдослучайных чисел (DRBG)

Дополнительные функции:

Метод 27 - выполнить все методы подряд

Метод 28 - вычислить SHA256 всех найденных значений

Метод 29 - вычислить обратные значения всех ключей по модулю N

Метод 30 - выполнить двойное хеширование SHA256(SHA256(...))

Сохранение результатов:

Программа автоматически сохраняет результаты в файлы:

private_key_generation_log.txt - лог операций

private_key_results.txt - основные результаты

Дополнительные файлы для специальных операций

Важные замечания
Все ключи генерируются в шестнадцатеричном формате.

Программа использует параметры кривой secp256k1 (используется в Bitcoin).

Для некоторых методов требуется дополнительный ввод (например, seed для DRBG).

Результаты всех операций сохраняются в словаре all_results до завершения программы.
